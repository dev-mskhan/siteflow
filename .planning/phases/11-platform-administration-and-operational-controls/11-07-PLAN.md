# Plan 11-07: Frontend integration, performance baselines, and release gates

## Objective
Wire the platform admin UI to server routes, record performance baselines, and verify release readiness.

## Tasks
1. Minimal platform admin UI: org/account search and detail, lifecycle action with reason, support grant request/approve, diagnostics read views. UI visibility is not a security boundary.
2. Baseline timings for organization search, billing summary, queue dashboard, audit history, with dataset size documented.
3. Update Swagger/OpenAPI and Archify docs from verified runtime behavior.
4. Operational notes: migration, rollback, recovery.
5. Run typecheck, lint, build, and the full server integration suite; record results separately from pre-existing failures.

## Acceptance criteria
- Every ROADMAP Phase 11 success criterion verified with recorded commands.
- No test reported as passing unless executed.
- Final diff reviewed for secret leakage and unrelated changes.
